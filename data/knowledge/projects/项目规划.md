# 个人智能体平台项目规划

## 项目目标

本项目计划建设一个面向个人使用的智能体平台，使用户能够：

- 查询个人资料和项目文档；
- 基于资料获得带来源的问答结果；
- 后续接入待办、日历、笔记等受控工具；
- 对涉及写入的操作执行预览和确认；
- 保留必要的运行记录与审计信息。

## 第一阶段：基础对话与 BM25 知识检索

第一阶段不使用本地大语言模型，也不依赖本地 Embedding 模型。

对话能力通过远程 DeepSeek 服务提供，当前可选模型包括：

- `deepseek-flash`
- `deepseek-v4-pro`

知识检索采用 BM25 关键词检索方案，主要组件为：

- `rank-bm25`：BM25 排序；
- `jieba`：中文分词；
- JSON 文件：保存文档切片及来源信息。

第一阶段仅处理 Markdown 和纯文本资料。

## 第一阶段验收标准

完成后应满足：

1. 可以把 `.md` 和 `.txt` 文件放入 `data/knowledge/`；
2. 可以执行索引构建命令并生成 `chunks.json`；
3. 用户提问时能检索出相关片段；
4. 回答能够列出实际使用的来源文件；
5. 知识库没有相关资料时，系统明确说明资料不足；
6. 不因资料不足而编造答案；
7. DeepSeek API Key 仅保存在 `.env`，不写入代码或知识库。

## 第二阶段方向

第一阶段稳定后，可逐步增加：

- PDF、Word 文档解析；
- 文档标题、标签和更新时间等元数据；
- BM25 与向量检索混合排序；
- 文档增量索引；
- 用户权限与资料访问范围；
- 知识库问答评测集；
- 引用片段定位和原文跳转。

## 技术原则

- 先保证可用和可验证，再增加复杂能力；
- 先采用只读知识问答，再接入有副作用的工具；
- 所有外部写操作都应遵循“预览、确认、执行、回读”的流程；
- 工具失败、接口超时或资料缺失时，不得报告为已完成；
- 敏感配置必须通过环境变量或专用密钥管理机制保存。
