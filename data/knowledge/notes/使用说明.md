# 个人智能体平台使用说明

## 平台用途

个人智能体平台用于整理个人知识资料，并基于已导入的文档回答问题。

系统采用以下流程：

1. 用户提出问题；
2. 系统从知识库中检索相关文本片段；
3. 将检索到的片段连同问题发送给 DeepSeek；
4. DeepSeek 根据片段生成回答，并标明资料来源。

如果知识库中没有足够依据，系统应明确说明：

> 知识库中未找到足够依据。

系统不应把模型自行推断的内容表述为知识库事实。

## 支持的资料格式

第一阶段支持以下格式：

- Markdown：`.md`
- 纯文本：`.txt`

知识资料统一放入 `data/knowledge/` 目录。

建议按主题分类，例如：

- `notes/`：个人笔记、会议纪要、经验总结；
- `projects/`：项目计划、设计文档、复盘记录；
- `manuals/`：操作手册、规范和流程说明。

## 更新知识库后的操作

每次新增、修改或删除知识资料后，都需要重新构建索引：

```bash
uv run python -m scripts.ingest_knowledge
```

索引构建完成后，系统会更新：
`data/index/chunks.json`
该文件保存文档切片、来源路径和必要元数据。

安全要求
以下内容不应放入知识库：

API Key、Token、密码；
.env 文件；
私钥、证书和 SSH 密钥；
Cookie、会话信息；
未脱敏的个人隐私数据；
数据库导出文件和生产日志。
