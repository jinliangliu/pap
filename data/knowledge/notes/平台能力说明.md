# 平台能力说明

本文列举 Personal Agent Platform 当前提供的能力，供「平台能做什么」这类问题检索引用。
每条能力对应仓库里的实现，不写规划中或尚未上线的功能。

## 能力清单

| 能力 | 说明 |
|---|---|
| 对话与请求规划 | 接收用户消息，由规划器生成 ActionPlan，决定普通对话、只读工具、写操作预览或知识问答 |
| 知识库问答 | 检索已入库的资料，返回带来源引用的原文摘录；资料不足时明确说明，不用模型常识补写 |
| 知识库管理 | 页面上传与目录同步两条入口，支持列表、详情、下架、重建、增量同步、检索验证 |
| 受控工具调用 | 工具只能从注册表调用，内置工具、远端 MCP 工具、自定义 HTTP 工具均需登记后才对模型可见 |
| 代码沙箱 | 通过 HTTP 委托给外部沙箱执行 Python / JavaScript，平台自身不执行模型或用户给出的代码 |
| 写操作审批 | 先生成预览，用户单次确认后执行，执行后回读核验并落审计；使用服务端生成的幂等键 |
| 会话管理 | 保存会话历史，支持查看、重命名、删除；多轮状态由 checkpointer 持久化 |
| 对话附件 | 按租户与用户隔离上传、列出、下载附件；图片与 PDF 可经 OCR 工具提取文字 |
| 技能 | 控制台维护作业指令、触发词与工具白名单，规划前确定性命中并注入 |
| 长期记忆 | 记录已确认的稳定事实，下一轮作为背景注入；自动抽取的只是候选，需人工确认 |
| 多租户与权限 | 可信身份解析租户，ORM 过滤与 PostgreSQL RLS 双层隔离；角色、scope、站点授权与配额 |
| 观测 | 记录 trace 与 span，展示 Skill 命中、工具与模型循环、最终答复与链路耗时；开发期开关控制 |
| 运维接口 | `/health`、`/ready`、`/metrics`，限流、巡检告警与审计日志 |
| 控制台 | 配置、知识库、技能、观测、审批、会话、附件、租户管理的 Web 界面 |

## 知识库能回答什么

知识库存的是可引用的资料原文，回答「这件事的规定、参数、流程是什么」。
它不回答「这个人偏好什么」（由长期记忆处理），也不回答「这类活按什么步骤干」（由技能处理）。

检索采用 BM25 关键词排序加语义重筛：先按权限与数据分级过滤，再召回候选片段，
由模型剔除字面撞词但语义无关的假阳性，最终按检索原序返回原文摘录与引用。
引用的标题可以点开，跳转到知识库页并高亮命中的切片。

## 当前边界

- 没有向量检索：查询词与资料完全没有字面交集时，BM25 返回 0 条，语义重筛救不回未被召回的片段。
- 引用只定位到切片，不定位到句子；切片最多 800 字符。
- 写操作一律需要审批，不存在「直接执行」的旁路；外部调用超时或异常按执行结果未知处理，不自动重发。
- 未配置外部服务地址的工具进入显式 mock 模式或根本不注册，返回值带 `source=mock`，不得当作真实数据。
- 观测是开发期调试手段，生产默认关闭；Checkpointer 单机用 SQLite，多实例需换 PostgresSaver。

## 入口

- 对话：`POST /api/v1/chat`
- 知识检索验证：`POST /api/v1/knowledge/search`，请求体 `{"query": "...", "limit": 4}`
- 健康检查：`GET /health`、`GET /ready`
- 控制台：配置、知识库、技能、观测、审批等页面
