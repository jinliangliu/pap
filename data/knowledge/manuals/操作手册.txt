个人智能体平台操作手册

一、启动前检查

1. 进入项目目录：
   cd /personal-agent-platform

2. 确认环境变量文件存在：
   .env

3. .env 中应至少包含：
   OPENAI_API_KEY
   OPENAI_BASE_URL
   OPENAI_MODEL

4. 当前项目使用远程 DeepSeek 服务，不需要在 ECS 本地下载或运行大语言模型。

二、导入知识资料

1. 将 Markdown 或 TXT 文件放入以下目录之一：
   data/knowledge/notes/
   data/knowledge/projects/
   data/knowledge/manuals/

2. 不要导入密钥、密码、Token、私钥、Cookie 或未脱敏隐私资料。

3. 新增或修改资料后，重新构建知识索引：
   uv run python -m scripts.ingest_knowledge

4. 构建成功后，检查以下文件是否生成：
   data/index/chunks.json

三、验证检索

构建索引后可直接调用检索接口验证：
   POST /api/v1/knowledge/search
   请求体：{"query": "审批有效期是多少秒"}

预期结果：返回相关片段，并附带 citations 来源引用；
对无关问题不应返回明显不相关的资料。

四、启动服务

开发环境启动命令：
   uv run uvicorn app.main:app --reload

启动后可访问健康检查接口：
   /health

五、常见问题

问题：索引构建结果为 0 个片段。
处理：检查 data/knowledge 目录中是否有 .md 或 .txt 文件，确认文件不是空文件。

问题：检索不到预期内容。
处理：检查问题中的关键词是否出现在文档中；可在文档标题和正文中补充更明确的关键词；然后重新构建索引。

问题：模型回答了资料中没有的内容。
处理：检查调用模型时的提示词，要求模型仅依据检索片段回答；资料不足时必须明确说明“知识库中未找到足够依据”。

问题：API 调用失败。
处理：检查 .env 中的 OPENAI_API_KEY、OPENAI_BASE_URL 和 OPENAI_MODEL 是否正确；确认所用模型名称是服务端实际可用的模型。
